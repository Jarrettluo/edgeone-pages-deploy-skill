# Edgeone Pages Deploy

> Deploy frontend and full-stack projects to EdgeOne Pages (Tencent EdgeOne). Use when the user wants to deploy, publish, ship, host, launch, or go live on EdgeOne Pages — e.g. "deploy my app", "publish this site", "push this live", "deploy and give me the link", "create a preview deployment", "deploy to EdgeOne", or "ship to production".

## 安装

将本仓库放到 OpenClaw 技能目录即可使用：

```bash
git clone <本仓库地址> ~/.openclaw/workspace/skills/edgeone-pages-deploy-skill
# 或放入 ~/.openclaw/skills/
```

## 配置

如需 API Key、邮箱授权码等配置，请参考 `SKILL.md` 中的说明，通过环境变量或本地 `.env` 文件设置（**不要提交到仓库**）。
